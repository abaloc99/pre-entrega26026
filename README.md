Sistema de Gestión de Productos - Pre-entrega Python
Este proyecto es una aplicación interactiva por consola desarrollada en Python para el curso Python Inicial - Talento Tech. Permite gestionar el inventario básico de una empresa utilizando listas anidadas, bucles y validación de datos.

🚀 Funcionalidades
1. Agregar producto: Registra el nombre, categoría y precio (sin centavos) con validación de entradas no vacías ni negativas.

2. Mostrar productos: Lista todos los productos registrados numerados con su correspondiente ID.

3. Buscar producto: Filtra la lista por nombre (coincidencia parcial o completa sin importar mayúsculas/minúsculas).

4. Eliminar producto: Remueve un producto del inventario mediante su número de posición/ID.

5. Salir: Mantiene el programa activo hasta que el usuario decida finalizar la ejecución.

🛠️ Tecnologías utilizadas
Lenguaje: Python 3.x

Estructuras de datos: Listas anidadas ([ [nombre, categoría, precio], ... ])

Control de flujo: Bucles while y for, condicionales if / elif / else

📋 Requisitos de ejecución
Tener instalado Python 3.8 o superior.
